ShyQuiet - Privacy-first AI assistant with stealth mode

## Architecture

Single Rust binary with unified GTK4 stealth window:
- Invisible overlay on Wayland (zwlr-layer-shell-v1)
- Chat View - AI interaction with Vision + Audio
- Settings View - API keys, model selection
- History View - Past conversations
- Prompts View - System prompts editor

## Stack

- Rust + GTK4 + libadwaita
- gtk4-layer-shell for Wayland stealth
- Groq API (LLM + Whisper STT)

## Features

- [x] Stealth window invisible in screen share
- [x] Unified ViewStack navigation
- [x] Audio recording (PipeWire/PulseAudio)
- [x] Screenshot capture (grim/gnome-screenshot)
- [x] Settings persistence
- [x] Docker build environment
